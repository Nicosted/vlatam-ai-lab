# AI Rules (Strict)

1. Work local-first and offline by default.
2. Never read `.env*` files.
3. Never use production credentials or production endpoints.
4. Never perform destructive file or git operations.
5. Never commit/push without explicit human approval.
6. Keep implementations minimal and reversible.
7. Prefer transparent markdown evidence over hidden automation.
8. Surface uncertainty and assumptions explicitly.
9. Require human review before any high-impact recommendation.
10. Preserve auditable traceability for every generated report.
