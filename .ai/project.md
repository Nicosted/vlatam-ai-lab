# Project Brief

## Name

vlatam-ai-lab

## Mission

Build a safe, minimal, and auditable sandbox for AI-driven regulatory intelligence workflows for vLatamGlobal.

## Scope (P0)

- Local-only PCRAM bulletin/NCM monitoring prototype
- Snapshot ingestion from local files
- Delta placeholder analysis
- Markdown evidence report generation

## Out of scope (P0)

- Production app features
- External API fetchers
- Databases, queues, or web UI
- Automated enforcement actions
